## 1. 方向：安静的界面，有表现力的内容

关键词：**内容优先、柔和层级、清楚选择、桌面效率、克制动效。**

- 色彩：保留现有海蓝种子色与 Monet 动态配色。界面主要使用中性表面，主色集中于主操作、选中、焦点和进度。
- 形态：MD3E 的圆润控件、连通分组和有弹性的空间变化；内容区保持稳定，不把每个控件都放大成移动端卡片。
- 密度：先统一现有鼠标与键盘布局，不新增紧凑模式设置。未来若需要密度切换，应单独评审；不能用缩小正文解决布局问题。
- 内容：封面、缩略图和作品决定画面的丰富度。首页不增加与任务无关的大型营销 Hero、装饰图表或统计卡。
- 桌面感：来自窗口行为、快捷键、右键、拖放、焦点和稳定布局。跨平台共用内容组件；系统差异集中在窗口壳。
- 轻量状态反馈与主内容分离：扫描放在任务区，播放放在持久播放条，普通成功反馈不打断浏览。

### 1.1 平台材质边界

| 区域 | 规则 |
| --- | --- |
| Windows / macOS 窗口壳 | 尊重系统窗口按钮、拖动区域和系统缩放；允许系统支持的原生材质 |
| 导航与内容区域 | 统一 MD3E 表面、字号、图标与状态；不因平台改成另一套内容组件 |
| 透明 / 模糊 | 现有导航与迷你播放条使用 `lm-glass`，保留其区域材质；普通表单、菜单和媒体列表不各自另造玻璃效果。播放条材质不能被“只允许窗口背景”规则误删 |
| 无材质 / 降透明 | 回落到对应语义表面；不靠模糊保证对比度，不依赖桌面壁纸可见性 |

本稿将 SPEC 中 Fluent / 液态玻璃 / M3 收敛为：**窗口壳与明确的播放材质区域可表达平台质感，产品控件语言统一。** 截图只能确认材质观感，不能证明使用了操作系统原生 Mica / Acrylic；具体实现以宿主和样式源码为准。

## 2. 令牌架构与唯一来源

只保留三个层级，依赖方向为基础 → 产品语义 → 组件映射。

| 层级 | 职责 | 真源 / 拟议归属 |
| --- | --- | --- |
| 基础 | 动态色、字阶、圆角、间距、动效 | 保留 `shared/m3-theme.ts`、生成色段与已有字体；补齐间距尺度 |
| 产品语义 | 页面边距、内容间隔、密度、表面、文本、焦点和状态 | 后续集中在 `src/tokens/` 的产品语义层，沿用 `--lm-*` 前缀 |
| 组件映射 | 将产品语义映射到 `--m3e-*` 以及第三方播放器参数 | 由 UI 适配层集中维护；业务页面不写供应商内部变量 |

不新建平行的 `--sm-*` 或另一套颜色引擎。库的 `small/medium` 不是产品密度的定义，由适配层选择与产品几何匹配的档位。

已知现状：`theme.css` 已有颜色、字阶、圆角、动效和部分布局变量。首轮已补共享间距和搜索几何，详见 9.2；下表中的拟议颜色别名尚未添加到 CSS，继续使用现有生成颜色角色。

### 2.1 颜色语义

现有配色内核仍是唯一颜色算法。示例值是当前默认种子色的静态参考，**不是另一份应手写维护的色表**。

| 产品角色 / 拟议别名 | 现有基础角色 | 浅色示例 | 深色示例 | 用途 |
| --- | --- | --- | --- | --- |
| `--lm-surface-app` | `surface` | `#f9f9fe` | `#0c0e12` | 应用底 |
| `--lm-surface-nav` | `surface-container-low` | `#f2f3fa` | `#111318` | 拟议的导航实色回落；当前 `lm-glass` 合成效果不等同于该色块 |
| `--lm-surface-panel` | `surface-container` | `#eceef5` | `#161a1f` | 普通面板 / 搜索容器；不能统一覆盖设置连通列表与播放条材质 |
| `--lm-surface-overlay` | `surface-container-high` | `#e6e8f0` | `#1c2026` | 菜单、对话框 |
| `--lm-text-primary` | `on-surface` | `#2e333a` | `#e2e5ef` | 标题和正文 |
| `--lm-text-secondary` | `on-surface-variant` | `#5b5f67` | `#a7abb4` | 说明、元数据 |
| `--lm-action-primary` | `primary` | `#426089` | `#b1c8ec` | 主按钮、焦点 |
| `--lm-selection-container` | `secondary-container` | `#d8e3f8` | `#313c4c` | 导航、普通选择 |
| `--lm-selection-content` | `on-secondary-container` | `#475263` | `#b5c0d4` | 选择容器前景 |
| `--lm-border-subtle` | `outline-variant` | `#aeb2bb` | `#444850` | 必要的分隔和轮廓 |

- 强调色不是正文颜色；错误、警告、成功使用已有语义色，并同时提供文字 / 图标。
- `primary` 与 `on-primary`、选择容器与对应前景必须成对使用。主题扩展同时提供成对覆盖。
- 不用任意透明度把次要文字压得更淡。禁用文字 / 图标使用组件禁用语义；信息仍需可辨识。
- 默认未选媒体卡片不额外加厚底板；封面使用 `surface-container` 占位，文本直接置于页面表面。
- `scrim` 当前在项目内已是含 alpha 的颜色；不得再叠 opacity / 二次混色加深。蒙层透明度未来统一迁移时处理。
- 用户皮肤经过语义层影响产品组件；禁止按页面覆盖某个按钮来修复整套皮肤。
- 封面上的时长、推荐标记和收藏按钮是内容叠层，需有独立的高对比前景 / 遮罩角色。现有黑白遮罩与收藏色应集中归属，不直接换成页面底色；播放条收藏红心也不能被主色令牌抹成普通未选图标。

允许直接内容色的范围：媒体原图、用户画笔、波形 / 频谱数据、封面取色、播放器暗色画布、作品内文主题。它们必须留在内容边界内，工具栏和弹层仍读取自己的语义主题。

### 2.2 间距

基础阶梯：**0 / 2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 CSS px**。2 用于光学校正，4 用于细粒度布局；常规布局优先 8 的倍数。

| 产品变量 | 默认值 | 规则 |
| --- | --- | --- |
| `--lm-content-pad`（已有） | 24px | 普通页面基准；设置等专用模板使用有记录的区域边距，不随窗口变宽自动改成 32px |
| `--lm-layout-section-gap` | 32px | 不同内容区块 |
| `--lm-layout-group-gap` | 24px | 标题、工具栏、列表等相邻功能组 |
| `--lm-layout-item-gap` | 横向 16px / 纵向 20px | 对齐当前本地媒体与在线视频网格；未来令牌应区分行 / 列间距 |
| `--lm-layout-control-gap` | 8px | 同组控件之间 |
| `--lm-layout-icon-gap` | 8px | 图标与文字 |
| `--lm-layout-label-gap` | 4px | 标签与帮助文字 |
| `--lm-layout-panel-pad` | 24px | 普通面板内容；设置连通列表使用组件内边距，不再叠加一层面板 padding |

页面新增布局优先通过语义变量表达，不再随意挑选近似值。现有设置连通列表的 3px 分段间隙、8px 内侧圆角以及控件内部几何属于组件规则，不能机械替换成 8 的倍数。存量 14px 行间距等值应先核对视觉与组件用途再收敛；本稿不直接批量改值。允许 1px 分隔、窗口几何、媒体比例、Canvas 数据和光学校正；例外记录用途。

### 2.3 字体与图标

沿用现有本地字体资产：界面拉丁字符 Roboto，中文 Sarasa Gothic SC / 系统回退；播放器字体仍可独立配置。不新增字体包。以下按实际令牌与组件角色记录，撤回原稿将页面标题统一放大到 32px 的建议：

| 角色 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | title-large：22 / 28；当前 PageHeader 行高覆盖为 1.2 | 500 | “图片 / 视频”等页头及下拉入口，不由截图物理像素反推字号 |
| 分组标题 | title-medium：16 / 24 | 500 | 设置区块等，区块不另设统一 22px 大标题 |
| 设置选项正文 | body-large：16 / 24 | 400 | 连通列表内标签；保留当前较舒展的设置阅读层级 |
| 媒体条目标题 | body-medium：14 / 20；视频当前行高为 1.3 | 500 | 图片单行省略，视频最多两行，不强行统一成 16px |
| 正文 | body-medium：14 / 20 | 400 | 普通信息 |
| 操作标签 | 14 / 20 | 500 | 按钮、导航、Tab |
| 元数据 | 12 / 16 | 400 | 作者、数量、时间、辅助说明 |

- 窗口宽度不触发连续缩小字号。长标题省略，完整名称通过可访问名称与必要的提示提供。
- 数量 / 时长用等宽数字；中文正文不继承拉丁字距。
- 图标统一 Material Symbols Rounded；通用操作以 24px 为基准，紧凑变体按角色映射。当前搜索 20px、分段按钮 18px、排序 15px、视频元数据 13px 等不能一律扩成 20 / 24px；其中存量差异需在适配层逐类核对。
- 默认使用轮廓图标；选中项可填充。图标按钮必须有明确可访问名称。
- 不使用 Emoji 充当功能图标，不另造平行 SVG 图标集。

## 3. 桌面几何与密度

所有值为 **CSS px（逻辑像素）**，不等于物理像素。尊重系统缩放与应用缩放。

| 对象 | 本轮基线 | 依据 / 约束 |
| --- | --- | --- |
| 顶部标题栏 | 48px | 已有 `--lm-titlebar-height`；不等同于设置页内 App Bar |
| 主导航 Rail | 88px | 已有 `--lm-nav-width`；不新增自动展开导航 |
| 普通页面边距 | 24px | 已有 `--lm-content-pad` |
| 设置分类栏 | 256px，分类项 48px | `SettingsView.vue` 当前布局；与主导航 Rail 是不同区域 |
| 设置内容区域 | padding 16px 32px 40px；内容最大宽 1120px | 页面专用布局；不额外套通用页面边距 |
| 设置行 | `.row` 最小 48px；连通列表内覆盖为 44px | 这是内层行高度，不是最终列表项总高度；还需计入组件上下留白 |
| 通用按钮、输入、媒体条目 | 沿用现有组件变体，逐类建立映射 | 尚未完成实机尺寸核对，不把原稿的 40 / 48 / 56 当成已统一标准 |
| 筛选 Chip | 设置预设 32px，inline 变体 30px | 当前页面确有两种几何；是否统一需对照场景评审 |
| 持久播放条 | 72px | 已有 `--lm-miniplayer-height`；仅在满足显示条件时占用空间 |

交互目标与可视外形分开：触控热区沿用 SPEC 的不小于 48dp 要求；桌面鼠标布局不能因此无条件给每个 30 / 32px Chip 加独立 48px 槽位，导致现有分组被撑散。键盘焦点清晰、热区不重叠、标签可读是所有密度下的共同要求。尚未测量的组件尺寸保留待核对状态，不伪装成已落地的产品令牌。

### 3.1 窗口断点

先记录页面已有重排，不凭概念图另定全局断点：

| 范围 | 已确认基线 / 待核对事项 |
| --- | --- |
| 普通桌面壳 | Rail 基准 88px；未建立 1280 / 1440px 自动展开导航规则 |
| 设置视口 > 760px | 256px 分类栏 + 弹性内容栏；两栏平级独立滚动 |
| 设置视口 ≤ 760px | 当前实现改为单一纵向滚动，分类菜单横向滚动，隐藏分类组标题 |
| 其他页面的小窗口与低高度 | 逐页记录工具栏换行、列表和弹层行为；尚无统一验收结果 |

断点按 CSS 逻辑宽度记录；系统缩放与应用缩放单独核对。宽窗口不自动等于更宽导航、更大播放条或更大控件。窗口最小尺寸和新的全局断点不属于本轮文档纠偏的既定决定。

### 3.2 应用壳与导航

- 标题栏 → 主导航 + 主内容 → 持久播放条。页面滚动不带走标题栏 / 导航 / 播放条。
- 普通页面由主内容区域滚动；设置页采用分类栏与内容栏两个平级滚动区域，窄窗口才回到单一纵向滚动。禁止把后者误写成全局单滚动规则。
- 实机主导航显示图片、视频、音乐、书籍、游戏、百宝箱，设置固定在底部；图片 / 视频 / 音乐 / 书籍有数量角标。扩展等条件入口按现有配置出现，不凭概念图增加常驻收藏、历史等一级菜单。
- 本地 / 在线 / 创作等领域模式沿用页标题下拉；在线源内部的推荐 / 动态 / 搜索 / 我的使用连通分段。两级用途不同，不为“统一”重复显示来源 Tab 或改掉现有信息架构。
- 顶层导航当前项使用单一选中容器；现有 Rail 显示图标与短标签。设置页隐藏主 Rail，由设置分类导航承接当前任务，并提供返回入口。
- 长导航组独立滚动；设置等底部入口固定；扩展入口遵循同样的密度和状态。

## 4. 四种页面模板

### 4.1 媒体库 / 在线源

保留实机的两种页面组合，共享页头、表面与组件角色，不要求所有页面排列完全相同：

| 页面 | 当前结构 | 文档约束 |
| --- | --- | --- |
| 本地图片 | 标题下拉 + 副说明 → 搜索 / 排序 Chip / 数量 / 右侧重新扫描 → 方形缩略图网格 | 搜索作用域为当前本地库；排序有单一选中项与方向箭头；重新扫描是 tonal 维护动作 |
| 在线视频 | 标题下拉 + 副说明 → 推荐 / 动态 / 搜索 / 我的连通按钮组 → 刷新工具行 → 16:9 视频网格 | 搜索是该源内的页面模式，不强制常驻一条本地搜索框；刷新不升级成全页 filled 主按钮 |

- filled 用于动作主次与当前组件选中语义，不要求每页必须出现 filled 行动按钮；连通分段的 filled 当前项不计为一个业务主操作。
- 来源切换共享页头位置、导航上下文与反馈规则；允许因媒体任务不同采用不同工具栏和卡片元数据。
- 图 1 / 2 的本地图片使用 1:1 裁剪缩略图，当前 `ImagesView` 明确传入 `aspect=1`，并非瀑布流；完整原图由查看器承载，不将缩略图裁剪直接判为缺陷。图 3 视频使用 16:9。音乐 1:1、书籍 / 番剧 3:4 等其余类型仅为组件支持 / 后续核对项，本轮无对应实机图。
- 两类网格横向间距 16px、纵向 20px；本地图片最小列宽参数 180px，在线视频网格最小列宽 250px。列数由可用宽度决定，不统一成原稿的最小宽 144px。图片封面至文字间距当前 10px，视频为 8px，先记录为变体，不未经评审强改。
- 图片：文件名一行省略，分辨率独立次要行。视频：标题最多两行，作者与播放 / 评论统计分层；时长在封面右下，推荐理由可在左下，避免互相覆盖。
- 媒体卡片作为产品组件允许专门实现缩略图、虚拟化与内容叠层；基础按钮、搜索、菜单等仍优先使用 m3e。不能只凭截图外形判定某个控件是自绘，组件归属以源码为准。
- 当前图片点击打开查看器，在线视频点击进入视频页面；不把所有媒体点击统一成“详情”。右键、批量选择等未在静态截图中展示，应按已有行为另行核对。
- 同时给出总量与筛选结果，不把筛选后的数量伪装成总库数量。

### 4.2 设置

沿用当前专用设置布局：隐藏应用主 Rail，页内 App Bar 提供标题与返回，左侧为设置搜索与分类，右侧为设置内容。大窗口两栏独立滚动；≤760px 使用官方 Filter Chip 构成横向可滚动分类与单一纵向滚动。旧 nav-menu 的内部布局仍是纵向，单改宿主 flex 无法实现横排；因此紧凑布局使用独立导航呈现，共享同一分类状态，扩展入口只挂载一份。

- 设置区块标题在组外；选项由现有 `m3e-segmented-list` 连通列表承载。相邻选项允许各有表面与小间隙，首尾组成大圆角轮廓；不能误归为“每行都套卡片”而抹平组件形态。外层 `m3e-card` 当前透明、无额外内边距，不再加第二层底板。
- 选项表面沿用 `surface-container-low`，不是一律改成 `surface-container`。组间距 24px，组标题下距 12px；列表左右内边距 24px，上下留白按组件的一 / 二 / 三行变体处理。
- 设置标签在连通列表内使用现有 `body-large`，不能按全局正文 14px 强制缩小。帮助文字、状态与复杂表单保留自己的语义层级。
- 标签 / 帮助文字居左，值或控件居右；帮助文字换行时行高增长，不挤压控件。
- 行容器负责间距、标签、帮助文本和搜索锚点；控件负责输入与状态。
- 开关行可整行触发一次切换；滑块、选择器、链接、文本输入的整行不劫持控件操作。
- 即时生效与需重启必须明确。显式保存只用于需要整体提交的配置，不混用隐式写入。

### 4.3 详情 / 阅读 / 创作

- 详情沿用页头、返回入口和操作优先级；长内容不强制与媒体网格使用相同最大宽。
- 阅读正文最大宽 720 左右作为默认起点，用户排版设置优先；工具栏使用产品 UI 字体。
- 创作区域让画布 / 文本占主体；工具面板遵循同一密度，不因工作台引入另一套开关、输入框和弹层。

### 4.4 沉浸播放器

先区分三张实机图中可见的**迷你播放条**与未展示的沉浸播放器：

- 迷你条固定于主内容下沿，普通壳下从 Rail 右侧开始，不覆盖左下设置入口；上沿进度轨道 4px，总高度沿用 72px。内容区需预留播放条高度和底部边距，验收最后一行媒体能完整滚入可见区。
- 作品封面与曲名 / 艺术家居左；时间、收藏、上一首、突出显示的播放 / 暂停、下一首、展开入口居右。播放按钮层级强于两侧传输控制，不能全部扁平化为同色图标。
- 保留深浅主题中的播放条材质差异；图 1 / 2 可见蓝色调，图 3 更接近深色。不得据此断言具体封面取色算法，亦不把条面强制映射为普通 panel 色。
- 迷你条内部沿用 `MiniPlayer.vue`：封面 48px、内容水平 padding 16px；内部行距与控件变体作为组件几何单独归属，不直接复用媒体网格样式。

以下沉浸播放器规则保留为设计目标，本轮截图未覆盖：

- 保留现有深色播放器、歌词字体和背景算法。封面取色限定在明确的播放材质 / 沉浸内容区域，不蔓延到普通搜索和表单。
- 播放器工具、菜单和对话框在显式的深色语义主题里渲染；不能继承背景图的随机颜色。
- 位置、播放、音量和队列控件有固定区域。歌词滚动与空间动画遵守系统减少动态效果偏好；不据概念图宣称已有应用内对应设置。
- 退出后恢复先前页面、滚动位置与焦点；播放会话不依附页面挂载。

## 5. 组件所有权

| 分类 | 包含 | 实现规则 |
| --- | --- | --- |
| 基础控件 | Button / IconButton / TextField / Select / Switch / Slider / Chip / Menu / Dialog / Snackbar | 优先使用现有 `@m3e/web`，通过轻量产品适配统一属性、尺寸、事件与名称；不复制库的内部 DOM / CSS |
| 产品模式 | PageHeader / FilterBar / SettingsGroup / SettingRow / EmptyState / ErrorState / LoadingState / MediaCard / MediaListRow | 产品持有；只组合基础控件与语义令牌，公开稳定插槽 / 行为 |
| 专业内容 | 歌词、频谱、播放进度、画布、阅读正文、虚拟列表 | 允许自定义实现和专业依赖；共享焦点、工具栏、主题边界与弹层规则 |
| 宿主控件 | 窗口标题栏、系统窗口按钮、托盘、桌面歌词壳 | 保留平台行为，集中宿主适配，不套通用业务按钮取代系统语义 |

适配层不做“通吃所有属性的巨型组件”。仅统一产品变体与公共行为；供应商补丁单独登记版本、复现和退出条件，不散到业务页。现有全局 Popover 与延时 slotchange 补丁待单独验证，不在设计阶段删除。

`@m3e/web` 是本项目选择的组件供应商，不等同于 Material 规范本身。选择器、对话框等控件是否支持目标密度、事件、焦点和重连时序，要在实现试点中验证。

## 6. 交互契约

### 6.1 状态

| 状态 | 统一表达 |
| --- | --- |
| 默认 | 语义前景 + 对应表面 |
| Hover | 基础控件复用库状态层；媒体封面保留当前抬升 / 轻缩放的专用反馈。共享同类映射，不改变文档流或给所有控件加同一种放大 |
| Pressed | 库提供的状态层 / 形变；内容不出现不必要位移 |
| Focus-visible | 2px 主色轮廓 + 2px 间隔，不能被 overflow 裁掉；与选中态可同时出现 |
| Selected | 选择容器 + 前景，辅以勾选 / 图标填充；不只改变文字颜色 |
| Disabled | 组件禁用态；禁用原因在邻近说明中可获得，不用不可聚焦提示藏住原因 |
| Loading | 保持按钮宽度，短任务用局部指示，长任务显示进度 / 可取消动作 |
| Error | 错误文本 + 对应图标 / 字段状态；保留用户输入和可恢复动作 |

2px 焦点规范是产品目标；当前媒体卡片 outline-offset 为 4px、页标题下拉为 2px，应按角色归并，不能因像素不同立即判错。库原生焦点呈现需在适配试点中验证等效性，不通过侵入 Shadow DOM 强行重画。

### 6.2 键盘、指针与提示

- Tab 顺序跟随视觉 / DOM 顺序；列表与分段选择遵循其相应键盘模式，禁用项不会成为死路。
- Space / Enter 激活相应控件；输入框编辑时不触发全局播放快捷键。
- Escape 只处理最上层可关闭浮层；焦点回到触发器。对话框内焦点受控，背景不能误操作。
- 图标操作悬停后提供文字提示，焦点进入也能看到；提示不能成为唯一操作说明。
- 危险操作描述对象和后果；删除与移入回收站分开命名。已有可恢复操作优先提供撤销。
- 拖拽是加速方式，导入 / 移动等关键任务同时提供可发现的按钮或菜单。

### 6.3 弹层与反馈

- 下拉与右键使用 Menu；聚焦任务使用 Dialog；非阻塞补充信息使用侧面板；Bottom Sheet 留给确有收益的紧凑 / 沉浸场景。
- 后续应收敛统一 Overlay 入口，集中处理宿主、焦点、Escape、滚动锁、触发器回焦和卸载；这是架构目标，不是三张截图能证明的现状。
- 原生 top-layer 的库组件遵守其生命周期，不靠更大的 z-index 修复时序。普通文档层级计划为 base / sticky / player / overlay-host / notification，映射由适配层集中维护。
- Snackbar 表示操作反馈；后台任务状态留在任务区；字段错误留在字段旁；禁止同一失败同时弹窗、Toast、Snackbar 三重打扰。

### 6.4 动效

优先复用组件库的动效和现有 motion tokens。需要新增时，按以下角色集中定义，不由页面决定时长：

当前源码基线：图片与视频封面均有约 220ms 的抬升 / 轻缩放；分段面板为 260ms、28px 方向位移，并已处理系统减少动态效果偏好。这些不是截图可见的事实，不将原稿的 220ms 页面切换目标反写成当前实现。静态图不能验收动画手感，本轮不要求删除已有反馈。

| 场景 | 产品目标 |
| --- | --- |
| 悬停 / 状态颜色 | 约 120–160ms，effects，不回弹 |
| 选择 / 小幅展开 | 约 200–240ms，fast spatial |
| 页面内容切换 | 约 220ms，轻微位移与透明度，不模拟手机全屏横滑 |
| 大型面板展开 | 约 420ms，复用 spatial 弹簧 |

后续需要补齐短反馈令牌并映射已有角色；本轮没有改写现有全局 motion 值。动画可打断，连续输入不排队；减少动态效果时取消空间位移、封面飞行和非必要循环，只保留即时状态或短淡入。

## 7. 状态页面与内容文案

所有媒体源遵守同一套状态槽位：首次空库、搜索无结果、加载、局部失败、离线 / 授权失效、分页结束。

- 首次空库：说明可导入的内容和一个导入按钮。
- 无结果：显示当前查询、清除筛选动作，不能引导重新扫描代替清筛选。
- 在线源失败：说明哪个源、失败类型与重试 / 登录入口；本地内容继续可用。
- Loading：占位与最终内容形状一致，加载结束不引起整页跳动。
- 文案用具体动作：导入文件夹、重新连接、移入回收站；不用“确定一下”“神秘错误”。
- 示例预览中的媒体封面、条目数和名称仅为演示数据，不代表真实用户库。
