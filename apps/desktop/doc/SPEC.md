## 一、项目定位

**本地优先（local-first）的全媒体库桌面应用。** 用户指定目录，应用建立索引，
在一个界面里浏览、整理、播放**图片 / 视频 / 音乐 / 小说 / 绘画 / 书籍 / 番剧**。

### 1.1 边界：做什么

- **单机优先**：数据、索引、缓存全部落在本机。无云同步、不强制账号。
- **在线源是增益，不是依赖**：所有在线源默认关闭，由用户在设置里逐个开启。
  关掉全部在线源后，应用必须是一个完整可用的本地媒体库。
- **多源聚合**：同一内容可来自多个源（音乐、小说、番剧），可换源、可兜底。
- **可扩展**：第三方能自带引擎与前端写扩展，主项目体积不随扩展增长。

### 1.2 边界：不做什么

- **不做云服务 / 不做账号体系**。没有登录才能用的功能。
- **不上传用户媒体**。任何网络请求都必须是用户主动触发的功能所需。
- **不内置广告、不做内容分成**。
- **不为在线源稳定性做承诺**：上游接口随时可能失效，应用只保证「失效时报错清晰」，
  不保证「永远可用」。
- **不做反向工程类灰色功能**（批量注册账号、绕过付费墙等）。

## 二、设计原则

### 2.1 界面（来源：[`archive/LumiLuna设计指南v1.md`](archive/LumiLuna设计指南v1.md)，历史归档）

| 原则 | 落地要求 |
|---|---|
| **Emoji 零容忍** | 界面/组件/提示中禁止 Unicode Emoji，一律 Material Symbols Rounded（`material-symbols-outlined`）。图标字体是**本地子集**，新增图标后必须重跑 `npm run fetch:icon-font`。 |
| **内容即英雄** | 主视觉由用户媒体（封面 / 缩略图 / 照片）主导；UI 元素不喧宾夺主。 |
| **简洁至上** | 核心功能链路操作层级 ≤ 3 步；右键菜单 / 底部 Sheet 聚合高频操作。 |
| **平台原生感** | Windows：Mica/Acrylic + Fluent 标题栏；macOS：液态玻璃 + 胶囊按钮；Android：纯正 M3。不做「异构网页」。 |
| **可访问性** | 正文对比度 ≥ 4.5:1；触控热区 ≥ 48dp；完整支持键盘 Tab / 方向键焦点导航。 |
| **沉浸与克制** | 全屏播放器独立用暗色主题（`#0F0F11`），不受系统外观影响；其余界面自适应系统主题。 |

### 2.2 技术

1. **官方组件优先**：能用 `@m3e/web` 官方组件（`m3e-button` / `m3e-search-bar` /
   `m3e-card` …）就不手写原生元素。手写「看起来像 MD3」的自拼实现**需要说明理由**。
   （用户原话：「现在共享组件抽出来统一，然后全部用正统的MD3E组件」。）
2. **同 UI 出现第 3 次即抽共享组件**，不复制 CSS。一致性由**结构**保证，不靠人记得同步。
3. **颜色是生成的，不是手写的**：改配色改 `shared/m3-theme.ts`，跑 `gen:m3-tokens`；
   手改 `theme.css` 的色令牌段会被单测挡下。同一原则适用于
   `settingsIndex.generated.ts`。
4. **渲染进程与原生层只有一个出入口**：`src/ipc/`（外加 `src/capabilities/` 门面）。
   业务代码不得直接触碰宿主 API —— 否则浏览器预览（`npm run dev:renderer` + mock）立即失效。
5. **跨宿主不变量**：业务代码只依赖 `silvermoon-ipc` 契约层。换宿主时，业务命令
   **一行都不该改**（两次迁移已验证：Rust 侧 19891 行里只有 537 行、约 2.7% 含宿主引用）。
6. **主进程不做业务**：Electron 主进程只做「宿主能力」——窗口、托盘、热键、协议、进程管理。
   业务逻辑一律在 Rust 侧，通过命令暴露。
7. **协议 = 权限边界**：`app://`（前端产物）/ `asset://`（本地文件）/ `app-cover://`（在线封面代理）
   各自承担明确职责；CORS 只回显受信来源，不下发 `*`。

### 2.3 工程

1. **可执行守卫优先于文档约定**。凡是「加了新东西必须同步改某处」的规则，
   都要有对应的 `verify:*` 脚本或单测。反例（已发生）：README 描述的架构与实际不符，
   横跨 133 个提交无人发现。
2. **生成物与真源分离**：版本号真源 `backend/silvermoon.config.json`（9 处校验）、
   配色真源 `shared/m3-theme.ts`、设置索引真源 `SettingsView.vue`。
3. **本机无 MSVC 时的验证链**：`verify:rust-pure`（wasm 旁路真跑断言）**只覆盖
   `TARGETS` 里显式列出的少数纯函数**（当前 3 项：扩展启动策略、引擎握手行解析、
   封面扩展名推断），**不等于 Rust 侧已验证**；其余一律走 CI。
   **不得把「本机编不了」当成不验证的理由**，也不得把「verify:rust-pure 绿了」当成全覆盖。
4. **提交信息只写定位**；**决策原因写 LOG / CHANGELOG**。

## 三、硬性约束（红线）

1. **禁止 `git add -A`**：仓库根常驻大量未跟踪的参考项目，以及 `.local/state` 中的敏感文件。
   一律显式列路径，提交前核对 `git diff --cached --name-only`。
2. **`capabilities/*.json` 已随 Tauri 时代废弃**：新增窗口**不需要**它，
   但要在 `electron/windows.ts` 创建、并确认属于可信来源。
3. **远程页（Pixiv / 文库8 / 番剧取流）命令白名单**：新增注入脚本的调用**必须**同步加进
   `electron/ipc.ts` 的 `REMOTE_WINDOW_ALLOWED_COMMANDS`。历史上漏掉一条就让文库8 登录静默失效。
4. **事件名与命令名不可改**：绑定靠字符串对齐，改名不报错、只静默失效。
5. **`toAssetUrl()` / `toCoverProxyUrl()` 是唯一认可的 URL 生成方式**：
   在线图片一律走封面代理（上游图床无 CORS 头且防盗链，直连必失败）。
6. **版本号改动不漏 fqapi**：`check-version.mjs` **不覆盖** `fqapi/Cargo.toml` 与
   `fqapi/Cargo.lock`，必须手动同步。
7. **`electron-builder.yml` 的 `extraResources` 只在平台级声明**，顶层不写（并发 copyfile 必踩 EBUSY）。

## 四、验收标准

### 4.1 每轮改动的收尾标准

| # | 项 | 判据 |
|---|---|---|
| 1 | 本地可跑的校验全绿 | `npm run lint` / `format:check` / `typecheck` / `test` 全部通过 |
| 2 | Rust 侧 | `verify:rust-pure` 通过（仅证明 `TARGETS` 内那几项纯逻辑）；改动涉及编译路径则推 CI |
| 3 | 生成物同步 | 改了配色/设置项/图标 → 对应 `gen:*` 已重跑，`verify:*` 通过 |
| 4 | 提交 | 显式列路径（禁 `add -A`），提交信息写清定位 |
| 5 | CI | 推送后确认 **Clippy 与 Rust 单测是 success，而非 skipped** |
| 6 | 真机验证 | **由用户人眼确认**；未确认的部分必须显式标注「未验证」 |

> **铁律**：AI 说「修好了」不算验证。未经验证的改动，在 LOG 里必须带
> `status: 未验证`，不得写成完成。

### 4.2 功能验收（版本级）

- **冷启动**：首屏可交互；启动过程有启动日志可追溯（`boot_log`）。
- **本地媒体库**：扫描 → 索引 → 浏览 → 播放/阅读，全链路可用；缩略图滚动时零额外命令。
- **音乐**：播放、歌词（逐字）、桌面歌词、SMTC、音效全部可用；
  **无声音 / 歌词不显示这类「功能完全没反应」必须先查日志再改代码**。
- **在线源**：开启后搜索 → 详情 → 取流/正文 → 播放/阅读可用；上游失效时报错清晰。
- **扩展**：装一个声明 `contributes.ui` 的扩展 → 导航项出现 → 页面块正确渲染。
  （`ext:` 协议已于 2026-10-22 补齐，本项无已知阻塞；修复记录见 §4.3，
  遥测/安全约束见 `AGENTS.md` Gotchas。）
- **数据安全**：旧数据迁移只读旧目录，绝不删改；卸载/清缓存不得误删用户媒体。
