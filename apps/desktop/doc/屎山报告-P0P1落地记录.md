### 路径防护的语义（照搬 Tauri 版，且刻意更严）

- 统一分隔符 → 逐段查 `..` → 大小写无关的前缀比较
- **只要出现 `..` 就拒绝**，即使规范化后仍在根内（比 `path.resolve` 更严；扩展 UI 是构建产物，正常路径不该有 `..`）
- 前缀比较必须带末尾分隔符，否则 `extensions-evil` 会被误判成在 `extensions` 之内

验证：`npx vitest run electron/__tests__/extProtocol.test.ts` → **14/14 通过**。
产物验证：`npm run build:main` 后 `dist-electron/main.cjs` 的 `registerSchemesAsPrivileged([...])` 有 **4 个** scheme 条目，
第 4 个只有 `standard/secure/supportFetchAPI/stream`（无 corsEnabled / bypassCSP），与设计意图一致。

> **未实机验证**：没有真的装一个带 `contributes.ui` 的扩展看 iframe 是否渲染。静态证据齐全，运行时表现需人眼确认。

### 为什么 `.state` 不抽（这条比「抽了多少」更重要）

原本的停止条件（「有人用了 class="state" 却没定义 .state」）**没有触发** —— 20 个使用者全部自带定义。
但存在一个**等价的静默回归**：scoped 只覆盖组件自己声明过的属性，抽成全局后，另外 12 个使用**不同变体**的
文件会开始继承它们从没声明过的属性。实测泄漏 7 个文件：

| 文件 | 会多出什么 | 后果 |
|---|---|---|
| `ExtensionsView.vue` | `text-align:center` / `color` / `padding:24px 0` | `.state` 本是 `padding:1px 8px` 的行内小徽章，被撑成 24px 高的居中块 —— 布局明显崩 |
| `NovelReader.vue` / `NovelFqapiView.vue` / `BookReader.vue` | `font-size` / `color` | 字体变小 |
| `BilibiliRelatedList.vue` / `BilibiliDynamics.vue` / `BilibiliComments.vue` | `padding` / `text-align` | 空态胶囊变居中大块 |

所以省下的行数是 0，但换来了这 7 处外观确定不变。**这正是「逐字节相同 ≠ 可以合并」的典型反例**：
规则内容一样，不等于它在全局作用域下影响面也一样。

### 一处刻意的语义统一

全局写的是 `.feed-hero:hover:not(:disabled)` 而不是 `:hover`。
KugouFeed 的 Hero 按钮在歌单为空时是 `disabled` 的，基线里它本来就用 `:hover:not(:disabled)` 挡住抬起；
另两个组件（NowPlayingFeed / BilibiliMinePanel）的按钮永不 `disabled`，因此对它们**完全等价**。
若全局写成 `:hover`，KugouFeed 的禁用按钮会被点亮抬起 —— 这是抽取过程中唯一改到语义的地方，需重点看图。
